Crafty — Handmade Marketplace

A digital home for handmade businesses: a responsive marketplace that gives makers a shelf and buyers something with a story.

Role
Full-stack Developer
Focus
Marketplace · Responsive UI
Stack
HTML · CSS · JavaScript · Bootstrap · PHP · MySQL
Year
2024

Overview

Crafty promotes creativity and supports handmade businesses through an organised digital marketplace. It gives independent makers a proper storefront and gives shoppers a tidy, welcoming place to discover one-of-a-kind pieces.

Built end to end with PHP and MySQL on the server and a Bootstrap-powered responsive interface, Crafty balances an attractive design with the practical plumbing of a real marketplace — listings, categories, and smooth browsing on any screen.

Highlights

  • Attractive, fully responsive interface built with Bootstrap.
  • Organised listings that put handmade products front and centre.
  • PHP & MySQL backend handling data and user flows.
  • A marketplace designed to champion small, creative businesses.
