Overview

Most small businesses already live inside WhatsApp — so the booking should live there too. This service listens to a conversation, understands what the customer wants, offers available slots, and locks in a reservation, all without leaving the chat the customer already trusts.

Behind the simple conversation sits a clean Spring Boot backend: REST endpoints handle incoming messages, validate availability, and persist each booking, while the messaging layer keeps the dialogue feeling natural and human.

Highlights

  • Conversational booking flow — from first "hi" to a confirmed slot.
  • Real-time availability checks and conflict-free scheduling.
  • Automated confirmations and reminders to cut no-shows.
  • Spring Boot REST API with clean persistence and validation.
